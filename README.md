# Сибнефтекарт — единый сайт

Статический проект без сборщика. Точка входа — корневой [`index.html`](index.html). Головной сайт объединяет новости и программное обеспечение с двумя самостоятельными мини-сайтами: `serviceSncard` и `zaoSncard`.

## Структура

| Путь | Назначение |
| --- | --- |
| `index.html` | Главная страница и переходы ко всем направлениям |
| `news.html` | Новости и ссылки на архив публикаций |
| `software.html` | Программное обеспечение для АЗС, сети станций, процессинга карт и нефтебаз |
| `equipment.html` | Перенаправление старого адреса в `serviceSncard` |
| `assets/site.css`, `assets/site.js` | Стили, общая шапка и подвал головного сайта |
| `serviceSncard/index.html` | Главная страница ООО «Сибнефтекарт-Сервис» |
| `serviceSncard/equipment.html` | Категории оборудования для АЗС и нефтебаз |
| `serviceSncard/cards.html` | Изготовление пластиковых карт и требования к макетам |
| `serviceSncard/assets/` | Стили и общая разметка мини-сайта сервиса |
| `zaoSncard/index.html` | Главная страница АО «НПФ «Сибнефтекарт» и раздел обслуживания карт |
| `zaoSncard/news.html` | Новости АО «НПФ «Сибнефтекарт» |
| `zaoSncard/company-history.html` | История компании |
| `zaoSncard/shareholders.html` | Информация для акционеров |

| `zaoSncard/assets/` | Общие стили, логотип, навигация и интерактивность сайта АО |

## Навигация

В головном сайте разделы «Главная», «Новости» и «Программное обеспечение» открываются в текущей вкладке. Ссылки на «Оборудование» и «Обслуживание карт» открывают соответствующие мини-сайты в новых вкладках и отмечены иконкой внешнего перехода. Изготовление карт доступно в меню `serviceSncard`.

Внутри `serviceSncard` доступны главная страница, оборудование и изготовление карт. `zaoSncard` сохраняет собственную навигацию и содержимое.

Все локальные ссылки относительные. Общий визуальный язык основан на стилях `zaoSncard`: красный `#BF0706`, графит `#23262C`, светлый фон `#F5F5F5` и общий логотип. Головной сайт и `serviceSncard` подключают `zaoSncard/assets/styles.css` как базовый набор стилей и дополняют его собственными файлами CSS.

SVG-иконки хранятся в `assets/icons/` и используются в навигации, разделах ПО, оборудования и карт. Для карточек изготовления карт заданы отдельные CSS-классы, чтобы они не пересекались со стилями карточек топливных станций в `zaoSncard`.

Каждая площадка подписана в шапке и на первом экране: `SNCard` для головного сайта, `Сервис` для `serviceSncard` и `ЗАО СНКарт` для `zaoSncard`. Главные страницы также различаются фоном первого экрана.

## Содержимое и внешние ссылки

Страницы опираются на опубликованные материалы [sncard.ru](https://www.sncard.ru/), [snc-service.sncard.ru](https://snc-service.sncard.ru/) и [zao.sncard.ru](https://zao.sncard.ru/). Внешние ссылки ведут к исходным каталогам и архивам, а локальные страницы остаются самостоятельными HTML-страницами. Цены оборудования и карт не дублируются, поскольку они могут меняться.

Общие шапки и подвалы головного сайта и мини-сайта сервиса собираются из `assets/site.js` и `serviceSncard/assets/layout.js`. В HTML предусмотрена резервная навигация без JavaScript. Мобильное меню использует `zaoSncard/assets/app.js`.
